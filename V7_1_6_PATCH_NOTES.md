# RuiderCar v7.1.6

1. Theme preference is persisted: member preference is stored in the user record; guest preference is stored in the browser cookie.
2. Product detail provides return-to-browse controls at both the top and bottom.
3. Admin system settings now use one transactional save with cache refresh and post-write verification, fixing potential Help changelog/guide persistence issues.
4. Light mode improves date, time, select, multiselect, radio, checkbox, calendar, popover and menu contrast.
5. Member and admin quick replies show a persistent success notice after rerun; member reply text is cleared only after a successful send.
